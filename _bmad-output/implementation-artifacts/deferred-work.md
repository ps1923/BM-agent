## 当前阶段验收结论

项目记录包含核心功能、安全回归、窄屏页面与终端超时恢复验收；RAG 数据的确定性词面复算已通过，但专家评分和学生真实解题效果未测。2026-10-01 对公网 IP 的只读探测未建立 HTTPS 会话（HTTP `/api/me` 为 404，HTTPS 握手失败；按 IP 探测不代表域名虚拟主机状态）。系统仍处于最终全量审计，不宣称答辩最终通过。

- 2026-10-05 本机只读页面复验：`127.0.0.1:8000` 返回前端页面，浏览器无障碍树显示实际登录表单；`127.0.0.1:8080/api/me` 返回 JSON 401，符合未登录访问受保护 API 的行为。没有提交登录或写数据库；师生登录后流程及真实工作区页面尚未验证。健康探针初次 3 秒超时，扩大到 10 秒后 `/actuator/health` 返回 `503 DOWN`（约 6.0 秒），而 liveness/readiness 返回 `200 UP`；组件详情未暴露，故不能据此断言具体依赖（如 MySQL）是原因，也不能宣称应用健康。需在安全可观测的验收环境继续定位。
- 同日云端只读复验区分了两套环境：服务器内部 Spring API `/actuator/health` 返回 200，公网 Nginx 的 `/bm-agent/api/me` 返回预期 401；本机 Windows API 的 503 不能外推为云端故障。云端 `/bm-agent/` 页面 404，原因为 active release 没有 Nginx alias 所需的 `public/` 子目录；该发布布局仍待修复与授权验收，线上未作更改。
